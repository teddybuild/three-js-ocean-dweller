# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report a problem to the maintainer through
[GitHub's private vulnerability reporting](https://github.com/teddybuild/three-js-ocean-dweller/security/advisories/new),
or use GitHub's "Report abuse" link on the content or account involved.
